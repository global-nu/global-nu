# Conferences Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the conferences page the two sources it never had, place each conference on a map through a cascade that tries the structured data before scraping anything, and show a timeline and a photographed card.

**Architecture:** Two fetchers are ported from the personal site and wired into the existing daily pipeline; `tools/news/conferences.py` already merges and deduplicates three providers and is not touched. A new `tools/news/venue.py` owns the location cascade and its cache. A new `tools/news/figures.py` owns the two drawings, generated by the daily renderer rather than by `build.py`, because this data changes every morning.

**Tech Stack:** Python 3 (stdlib + PyYAML + Pillow via the existing image pipeline), SVG generated as text, vanilla JS for the card, jsdom for the JS test, the project's own `.venv`.

## Global Constraints

Copied from the spec; every task implicitly includes these.

- **No factual value from memory.** Dates, places and licences come from the fetched record or the cited source, never from what an implementer knows.
- **A dot in roughly the right country is worse than no dot.** A conference whose location cannot be established stays in the list and gets no marker.
- **`tools/news/conferences.py` is used, not revised.** If merging three sources reveals a defect in it, report it — that is a finding, not a licence to redesign the merge.
- **Every photograph carries author, licence and a link to its Commons file page.** A record whose licence cannot be established gets no photograph rather than an uncredited one. Licence checking is `tools/fetch_commons_images.py`'s job and is not reimplemented.
- **The page must build when any source, or every source, is unreachable** — skipped with a warning, yesterday's content kept with yesterday's timestamp.
- No CDN, no external runtime request from the built page. No hard-coded colours; a new foreground/background pair goes into `PAIRS` in `tools/tests/test_theme.js`.
- `site-src/content/conferences.md` is **generated** by `tools/news/render.py`. Never hand-edit it; change the renderer.
- Python is `./.venv/bin/python3`. Never commit anything under `var/`.
- Commit messages are prose in the register of `git log -5`. No `feat:`/`fix:` prefixes. Keep the `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>` trailer.
- `node tools/tests/test_mockup_contrast.js` passes; all thirteen suites are green before this work starts and must be green after.

- [ ] **Step 3: Write the cascade**

`tools/news/venue.py`. The order is the spec's, and the docstring must say why the conference's own page is last: it is thirty requests a day to other people's servers, and every conference site is built differently.

```python
def address_of(record: dict, log) -> str | None:
    """The best location string this record offers, before any geocoding."""
    e = record.get("extra") or {}
    # 1. Neutrino Unbound's own place — already clean ("Shanghai, China").
    if e.get("place"):
        return e["place"]
    # 2. INSPIRE's structured address.
    if e.get("address_structured"):
        return e["address_structured"]
    # 3. Indico's address: too verbose to print under a title, exactly right
    #    for a geocoder.
    if e.get("address"):
        return e["address"]
    # 4. The conference's own page, cached by URL including its failures.
    if record.get("url"):
        return _from_page(record["url"], log)
    return None
```

`_from_page` looks for schema.org `Event`/`Place` JSON-LD first and a postal-address pattern second, caches **every** outcome — success and failure — in `var/news/venuecache.json`, and returns `None` rather than a guess.

`locate_record` turns an address into `(lon, lat)` via `geocode.locate`, splitting city and country from the string, and returns `None` when the address is absent or the geocoder declines.
